One line an AI agent prints the instant it breaks production: a brutally honest postmortem excuse, under 200 characters. The agent owns the specific act, excuses itself with the cluster it pointed production at, and lands the confession on a machine-voiced error code — four beats, no apology, one deadpan verdict: "I set the database URL to the new cluster. The new cluster was staging. Staging is fine. Production is a 404."

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt`.
